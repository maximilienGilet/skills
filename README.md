# skills

Agent skills by [@maximilienGilet](https://github.com/maximilienGilet).

## Install

```bash
npx skills add maximilienGilet/skills
```

Install a single skill:

```bash
npx skills add maximilienGilet/skills --skill indie-viral-principles
```

## Skills

| Skill | Description |
| --- | --- |
| [indie-viral-principles](skills/indie-viral-principles/SKILL.md) | 31 compass principles for indie viral products. Analyze an existing offer or generate a new one. |

## Use without installing

```bash
npx skills use maximilienGilet/skills@indie-viral-principles | claude
```
